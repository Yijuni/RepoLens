# 模型分析

将结构地图和学习目标交给模型，并在返回前验证图与当前源码快照。

入口：analyze(index, goal, client, progress)。客户端仅需实现 complete(messages, max_tokens)，编排不读取凭据、不依赖具体 HTTP 传输。

流程：核对快照 → 受限地图与 schema → 模型 JSON → 结构和证据校验 → 再核对快照 → 返回图与用量。校验失败最多追加一次修正请求；服务保留上次可用图。

限制：目标最多 1000 字符，上下文最多 24,000 字符；最多 2 次请求、累计 32,000 token、每次最多 4096 输出 token。请求前以 UTF-8 字节数保守预估输入上界，返回后累计用量；缺少 usage 时标明估算。

这是一条固定的地图到图流程，尚无模型主动读取源码的工具探索循环。

验证：AnalysisTests 使用可控客户端检查成功、有限修正、耗尽、正文隐私与过期快照。运行方式见 [服务说明](../../../../README.md)。
