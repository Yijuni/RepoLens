# 架构图持久化

用户明确点击保存后，`save_graph(index, graph)` 将已校验的语义 IR 写入目标仓库 `.repolens/architecture.json`，使用临时文件和原子替换。文件只包含 IR、snapshot、模型名称、目标摘要和用量，不包含源码正文、工具原始响应或 API Key。

重新导入时由 `load_graph(index)` 读取并校验 snapshot、真实锚点和关系；过期、损坏或版本不匹配时返回空图及可读原因，服务继续显示本地静态预览。导入本身不写目标仓库。

验证：使用索引和模拟语义图测试保存、恢复、快照失效、损坏文件和写入失败；浏览器上传的临时快照默认不提供持久保存入口。
