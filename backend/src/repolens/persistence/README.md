# 架构图保存

`save_graph(index, graph)` 明确保存到目标仓库 `.repolens/architecture.json`，使用同目录临时文件、fsync 和原子替换。失败保留旧文件；拒绝符号链接和目录联接。导入不写目标仓库。

`encode_graph()` 产生同格式 JSON，供浏览器目录句柄写入或下载；`decode_graph()` 校验浏览器重新导入的文件。`load_graph()` 从本机目录读取，返回图或可读原因。

文件格式 v2 包含 IR v0.2、快照、生成信息、用量和不含正文的证据来源记录，上限 4 MB。加载重新校验 schema、指纹、锚点与关系；版本旧、损坏或快照变化均回退静态预览。旧原型 v1 文件需要重新生成，不自动迁移缺少证据的图。

浏览器支持目录访问 API 时可请求写权限并原地保存；路径导入由服务写入；仅支持文件上传的浏览器下载 JSON，由用户放入指定位置后重导入。

验证：PersistenceTests、EvidenceTests、JobTests 检查往返、过期、来源损坏、写入失败和无需模型的恢复。来源记录是可核对的材料说明，不是对模型语义正确性的签名证明。
