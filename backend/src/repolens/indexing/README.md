# 多语言索引

只读遍历目录，以 Python AST 和多语言轻量静态解析提取类、函数、import、入口候选和本地文件依赖，同时为常见文本源码提供浏览树。不导入模块、不编译或执行目标代码。

当前精确解析 Python；C/C++、Go、Java、JavaScript/TypeScript 和 Rust 提取常见静态依赖与符号线索；未知或复杂语法仍可只读浏览，并在索引警告中标记覆盖范围。

接口：scan_repository(path) 返回 RepositoryIndex；model_map() 返回模型可见的元数据；source(file_id) 返回经指纹核对的源码；assert_current() 检查索引是否过期。

文件 ID 由相对路径生成，符号 ID 由相对路径与限定名生成，快照随内容变化。源码行号从 1 开始；按符号打开时返回真实定义区间并高亮。模型地图不含源码正文或绝对路径。

默认分析上限为 200 个源码文件、单文件 512 KB、累计 8 MB；浏览树最多 5000 个常见文本文件、单文件 1 MB、累计 64 MB，目录最多 10000 个。可在仓库根目录 `config.toml` 的 `[limits]` 中调整。忽略隐藏/环境/构建目录、敏感文件、符号链接和 junction。超限与解析失败产生不完整警告。

支持普通、包内相对 import 与常见 src 布局；不保证动态导入、复杂命名空间包和外部依赖解析。

仅有文本、文档或未静态解析语言的项目也可导入。Agent 可通过只读工具读取浏览范围内的文件，不受静态解析文件数限制。项目清单包含 XML、go.mod 和 CMakeLists.txt；每次工具取证与保存前校验所有已索引文档指纹。

验证：运行后端测试中的 IndexTests，覆盖中文空格路径、相对导入、稳定 ID、过期检测、忽略规则与文件限制。命令见 [服务说明](../../../../README.md)。
