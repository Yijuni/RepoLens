# Agent

`explore(index, goal, client, ..., cancelled, on_event)` 返回通过校验的语义图；只在用户确认生成后调用。

状态顺序为 INDEXING → PLANNING → EXPLORING → SUBMITTING → RENDERING → IDLE。规划仅开放 `submit_plan`；探索使用显式注册的只读工具；最终通过 `submit_graph` 提交。非法参数和证据错误以工具结果反馈，提交修正受独立上限约束。

初始输入只有目标、语言/目录统计和少量文档入口。源码由工具按需读取。旧工具正文可从上下文移除，保留证据元数据；需要时重新读取。模型根据目标和证据决定继续探索还是单独调用 submit_graph。探索工具在最后一轮仍可用，不按累计 token、工具次数或剩余时间强制要求提交。

`on_event` 接收阶段、可读消息、轮次、工具名和累计 usage（请求数、工具调用数、token、估算标记和耗时）。用量仅用于监测，不是账户余额或停止条件。日志只包含事件元数据和用量，不含请求正文或工具参数。

轮数、上下文、单次输出、网络超时、总时限与提交修正仍受配置限制；取消在调用前后及工具之间检查，进行中的 HTTP 请求等待返回或超时。不能通过校验时不返回半成品。

验证：运行后端 unittest；WorkflowTests 检查规划、多轮探索、工具错误反馈、提交修正、取消、轮数/时间限制，以及超过旧 token/工具配额后仍由模型自主提交。真实效果需通过网页配置 Key 后显式测试。
