# 网页工作台

提供目录导入、模型设置、发送确认、文件依赖图、项目说明与只读源码。

index.html 定义结构，style.css 提供浅色响应式布局，app.js 负责同源 API、自动分层、选择与缩放。由 Python 直接提供资源，不需要 Node/npm 构建。

布局使用稳定 Kahn 分层，循环依赖剩余节点放入最后一层；语义组显示为节点标签。模型文本与源码使用 textContent/SVG 文本节点，不当 HTML 执行。凭据不写入 localStorage，设置成功后清空输入框。

手动验证：启动默认示例，应看到 4 个节点与 3 条依赖；点击节点/列表查看源码；未确认发送范围时不能请求模型；放大缩小应改变画布大小。

目前无拖拽、平移、分组容器、布局缓存、语法高亮、背包或聊天。
