# 网页工作台

提供 IDE 风格的目录导入、文件/符号树、模型设置、发送确认、分组依赖图、项目说明与只读源码。

index.html 定义结构，style.css 提供浅色响应式布局，app.js 负责同源 API 与工作区状态，graph.mjs 负责自动布局、分组折叠、节点拖拽、平移和缩放，source.mjs 负责安全文本渲染和锚点高亮。由 Python 直接提供资源，不需要 Node/npm 构建。

布局使用稳定 Kahn 分层，循环依赖剩余节点放入最后一层；语义组以可折叠容器展示，位置在会话内按稳定 ID 保留。模型文本与源码使用 textContent/SVG 文本节点，不当 HTML 执行。凭据不写入 localStorage，设置成功后清空输入框。

手动验证：启动默认示例，应看到 4 个节点与 3 条依赖；展开文件查看类/函数，点击符号后源码滚动并高亮对应行；拖动节点、画布和滚轮缩放；未确认发送范围时不能请求模型。

当前仍是原生 JavaScript 原型，不是 React/Monaco/React Flow；源码着色仍是轻量实现，不替代完整语言服务。尚无背包、聊天和多视图。
