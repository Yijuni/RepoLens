# Web 工作台

原生 HTML/CSS/JavaScript 三栏界面：文件/符号树、只读源码和交互架构图。Python 直接提供资源，无需 Node 构建。

`app.js` 管理导入、模型设置、确认、后台任务、SSE 进度、取消和保存；SSE 断开后用小型任务状态接口轮询。刷新页面可继续查看当前生成任务。用户确认前不请求模型。

目录导入优先使用浏览器 showDirectoryPicker，仅在点击事件中调用；不支持时退回文件夹上传或本地路径。支持目录句柄时保存会请求写入权限；其他情况提供服务保存或下载。浏览器选择器的真实系统窗口仍需人工检查。

`graph.mjs` 以强连通分量消除循环后分层，按语义组布局容器。折叠保留汇总连线，外部依赖组默认折叠；节点拖拽位置按稳定 ID 在会话内保留。render_spec 控制形状、配色和徽标，边显示类型标签、方向、置信度与推断提示。独立模块允许没有连线。

模块下方列出所有文件/符号锚点，可分别跳转。`source.mjs` 用安全 DOM 文本显示源码和行号，不执行模型 HTML。Key 不保存到 localStorage。

验证：后端测试、`node --check` 和可选 `node backend/tests/browser_smoke.cjs`。浏览器检查使用模拟模型，覆盖同意确认、生成、连线、多个来源、保存和恢复。DPI 模拟不能替代 Windows 实机缩放验收。

限制：仍为原生 JS/SVG 原型，无 Monaco、背包问答或多视图；泳道目前复用语义分组，500 节点性能尚未验收。
